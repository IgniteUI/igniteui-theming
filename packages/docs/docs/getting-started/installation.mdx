# Installation

:::info
Ignite UI Theming is a Sass-based theming framework, so to use it, you need to have Sass installed in your project.
:::

Ignite UI Theming is available as an npm package, so you can easily add it to your project using a package manager like npm:

## Quick Start

```bash
npm install -D sass igniteui-theming
```

## Framework-specific setup

Below are a few examples of what we think is the best approach for setting up the environment, installing Sass, and adding the Ignite UI Theming across different project types and frameworks.

<Tabs className="it-install-tabs" >
<TabItem value="react" label="React/Next.js" default>
1. First, create a new project:

  ```bash
  npx create-next-app@latest my-app
  cd my-app
  ```

During setup, choose the options you prefer — TypeScript or JavaScript, ESLint, etc.

2. Next, install Sass and Ignite UI Theming:

  ```bash
  npm install -D sass igniteui-theming
  ```

Finally, to start using Ignite UI Theming functions and mixins, import the main theming module in your `.scss{:bash}` file:

  ```scss
  @use 'igniteui-theming' as *; 
  ```

That’s it — now your React project is ready to use Ignite UI Theming.

</TabItem>

<TabItem value="angular" label="Angular">
1. First, install the Angular CLI (if you don’t already have it):

  ```bash
  npm install -g @angular/cli
  ```

2. Create a new project with Sass support:

  ```bash
  ng new my-angular-app --style=scss
  ```

The nice thing about Angular is that it has first-class support for Sass, so you can enable it right from the project creation step.

3. Next, install Ignite UI Theming:

  ```bash
  npm install -D igniteui-theming
  ```

4. To enable import aliasing of Ignite UI Theming, configure the Sass preprocessor by adding `stylePreprocessorOptions{:jsonc}` to your `angular.json{:bash}` file in the build options:

  ```jsonc
  {
      // other configuration...
      "stylePreprocessorOptions": {
        "includePaths": ["node_modules"]
      }
  }
  ```

  This configuration allows you to import the package directly without using relative file paths.

  5. Finally, to start using Ignite UI Theming functions and mixins, import the theming framework in your .scss file:

  ```scss
  @use 'igniteui-theming' as *; 
  ```

  That’s it — now your Angular project is ready to use Ignite UI Theming.

  </TabItem>

  <TabItem value="bun" label="Bun">
  Bun is a fast JavaScript runtime that works well with various frameworks and setups. This guide covers the core steps to add Ignite UI Theming to any Bun project.

  1. Install Sass and Ignite UI Theming:

  ```bash
  bun add -d sass igniteui-theming
  ```

  2. Create your theme styles file (e.g., `styles.scss{:bash}`):

  ```scss
  @use 'igniteui-theming' as *;
  ```

  3. **Build/Compile Your Styles:** The exact process depends on your Bun project setup:

  **For Bun with a framework (React, Vue, etc.):**
  - If your project uses a bundler, it typically handles Sass compilation automatically. Just import your Sass file in your main JavaScript/TypeScript file:
  
  ```typescript
  import './styles.scss';
  ```

  **For vanilla Bun:**
  - Compile Sass to CSS using the Sass CLI with the correct load path:

  ```bash
  bunx sass --load-path=node_modules styles.scss styles.css
  ```

  - For development with watch mode (auto-recompile on changes):

  ```bash
  bunx sass --load-path=node_modules --watch styles.scss:styles.css
  ```

  - Link the compiled CSS in your HTML file:

  ```html
  <!DOCTYPE html>
  <html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Bun + Ignite UI Theming</title>
    <link rel="stylesheet" href="./styles.css">
  </head>
  <body>
    <h1>Hello Bun!</h1>
  </body>
  </html>
  ```

  5. Run your Bun project according to your setup (e.g., `bun run index.ts{:bash}`, `bun dev{:bash}`, etc.).

  Your Bun project is now ready to use Ignite UI Theming!

  </TabItem>

  <TabItem value="webpack" label="Webpack">
  This guide shows you how to set up a Vanilla JavaScript project with Webpack and Ignite UI Theming from scratch.

  1. First, create a new project directory and initialize npm:

  ```bash
  mkdir my-webpack-app && cd my-webpack-app && npm init -y
  ```

  2. Install Webpack, Webpack CLI, and the necessary loaders:

  ```bash
  npm install -D webpack webpack-cli webpack-dev-server sass sass-loader css-loader style-loader
  ```

  3. Install Ignite UI Theming:

  ```bash
  npm install -D igniteui-theming
  ```

  4. Configure Webpack by creating a `webpack.config.js{:bash}` file in your project root:

  ```javascript
  const path = require('path');

  module.exports = {
    entry: './src/index.js',
    output: {
      filename: 'bundle.js',
      path: path.resolve(__dirname, 'dist'),
    },
    module: {
      rules: [
        {
          test: /\.scss$/,
          use: [
            'style-loader',
            'css-loader',
            {
              loader: 'sass-loader',
              options: {
                sassOptions: {
                  includePaths: ['node_modules']
                }
              }
            }
          ]
        }
      ]
    },
    devServer: {
      static: './dist',
    },
  };
  ```

  The `includePaths: ['node_modules']{:jsonc}` option allows you to import Ignite UI Theming directly without relative paths.

  5. Create your project structure. 

  First, create `dist/index.html{:bash}`:

  ```html
  <!DOCTYPE html>
  <html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Webpack App</title>
  </head>
  <body>
    <h1>Hello Webpack!</h1>
    <script src="bundle.js"></script>
  </body>
  </html>
  ```

  Then create `src/index.js{:bash}`:

  ```javascript
  import './styles.scss';
  ```

  And `src/styles.scss{:bash}`:

  ```scss
  @use 'igniteui-theming' as *;
  ```

  6. Add build scripts to your `package.json{:bash}`:

  ```jsonc
  "scripts": {
    "build": "webpack --mode production",
    "dev": "webpack serve --mode development --open"
  }
  ```

  Your Webpack project is now ready to use Ignite UI Theming. Run `npm run dev{:bash}` to start the development server.

  </TabItem>

  <TabItem value="webpack-existing" label="Webpack (Existing Project)">
  If you already have a Webpack project and want to add Ignite UI Theming to it, follow these steps:

  1. Install Sass and the necessary loaders (if not already installed):

  ```bash
  npm install --save-dev sass sass-loader css-loader style-loader
  ```

  2. Install Ignite UI Theming:

  ```bash
  npm install igniteui-theming
  ```

  3. Update your `webpack.config.js{:bash}` to configure the Sass loader. Find or add the module rules section:

  ```javascript
  module: {
    rules: [
      {
        test: /\.scss$/,
        use: [
          'style-loader',
          'css-loader',
          {
            loader: 'sass-loader',
            options: {
              sassOptions: {
                includePaths: ['node_modules']
              }
            }
          }
        ]
      }
    ]
  }
  ```

  The `includePaths: ['node_modules']{:jsonc}` option allows you to import Ignite UI Theming directly without relative paths.

  4. Create an SCSS file (e.g., `styles.scss{:bash}`) and import it in your JavaScript entry point (e.g., `index.js{:bash}`):

  ```javascript
  import './styles.scss';
  ```

  5. Import Ignite UI Theming in your SCSS file:

  ```scss
  @use 'igniteui-theming' as *;
  ```

  That's it! Your existing Webpack project can now use Ignite UI Theming.
