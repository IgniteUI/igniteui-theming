# Quick Start

The whole setup of the Ignite UI Theming framework is fairly simple. The only requirement is that the project supports Sass. The setup process is almost the same for all frameworks and project types, but there are still small differences. You can see more specific setup instructions for some of the more popular frameworks in the [Installation](installation) section.

## Install dependencies

First, the Ignite UI Theming package needs to be installed in your project. If Sass is not installed yet, install it as well.

```bash
npm install --save-dev sass igniteui-theming
```

:::info
You can also use the [__sass-embedded__](https://www.npmjs.com/package/sass-embedded) package instead of __sass__.
:::

## Load the framework

After the Ignite UI Theming package is installed, it needs to be loaded in your stylesheet.

```scss
@use 'igniteui-theming' as *;
```

Depending on your framework, you might need to configure [Sass load paths](https://sass-lang.com/documentation/at-rules/use/#finding-the-module) so the module can be imported directly, instead of using absolute or relative paths.
