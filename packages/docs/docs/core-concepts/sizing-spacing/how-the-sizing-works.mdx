# How the sizing works
  
  ## `sizable` mixin
  
  To make an element sizable, you need to include the `sizable{:sass}` mixin. Including the mixin declares three variables in the element's scope: `--is-small{:sass}`, `--is-medium{:sass}`, and `--is-large{:sass}`. Each variable holds a calculation that determines which of the three sizes — `small`, `medium`, or `large` — is applied to the element. These variables enable switching between the three sizes.
  
  It’s important to note that only the element where the `sizable{:sass}` mixin is included becomes sizable. Child elements inside it will not automatically inherit this behavior.
  
  ## `sizable()` function
  
	Use the `sizable(){:js}` function on a CSS property to define the sizes you want to switch between dynamically. The function accepts up to three values: the first for `small`, the second for `medium`, and the third for `large`. You must provide at least one value. If you provide only two values, the second is applied to both medium and large.
  
  ```scss
  // Here the small value is 10px, and the medium and large values are 20px
  width: sizable($sm: 10px, $md: 20px);
  ```
  
  You can also assign the value returned by the function to a variable. (Remember to interpolate it, so only the returned value is stored.)
  
  ```scss
  // Define sizes for small (10px), medium (20px), and large (50px) in a variable
  --size: #{sizable($sm: 10px, $md: 20px, $lg: 50px)};
  width: var(--size);
  ```
  
  ## Managing the size
  
  After setting up the sizes with the `sizable(){:js}` function, declare the `--component-size{:sass}` variable. This variable is essential because it drives the calculations for the `sizable{:sass}` mixin variables — `--is-small{:sass}`, `--is-medium{:sass}`, and `--is-large{:sass}` — and must always be present.
  
  The `--component-size{:sass}` variable should hold the size you want to apply to the element. Sizes are determined by three predefined variables: `--ig-size-small{:sass}`, `--ig-size-medium{:sass}`, and `--ig-size-large{:sass}`. Assigning one of these to `--component-size{:sass}` applies the corresponding size.
  
  - `--ig-size-small{:sass}` uses the first value passed to the `sizable(){:js}` function.
  
  - `--ig-size-medium{:sass}` uses the second value.
  
  - `--ig-size-large{:sass}` uses the third value.
  
  You can also use numbers instead of the full variable names:
  
  - `--ig-size-small{:sass}` -> `1`
  
  - `--ig-size-medium{:sass}` -> `2`
  
  - `--ig-size-large{:sass}` -> `3`
  
  Both of these approaches are equivalent:
  
  ```scss
  .wrapper {
    ...
    --component-size: var(--ig-size-medium);
    --component-size: 2;
    ...
  }
  ```
  
  Either approach applies the medium size to the element.
  
  :::note
	  Setting `--component-size{:sass}` to medium, for example, will cause all CSS properties that use the `sizable(){:js}` function in the current scope to be sized with the medium value.
  :::

  You can also set `--component-size{:sass}` to reference another variable and define a default size:
  
  ```scss
  // Hooks the element size to the --ig-size variable and sets the --ig-size-medium as the default size
  --component-size: var(--ig-size, var(--ig-size-medium));
  
  // Sets the element size to the large value
  --ig-size: var(--ig-size-large);
  ```
  
  This is especially useful when you want to change all child elements' `--component-size{:sass}` values simultaneously.
  
  ## How the calculation is made
  
  After the `--component-size{:sass}` value is set, the calculations of the three variables: `--is-small{:sass}`, `--is-medium{:sass}`, and `--is-large{:sass}`, determine which size is active. The selected size is assigned a value of `1`, while the others remain `0`. The `sizable(){:js}` function then multiplies these variables by the size values passed as parameters. Since two of them are `0`, only the active size produces a positive result in the calculation, and that value is applied to the element property.
  
  ```scss
  .wrapper {
    @include sizable();
    width: sizable($sm: 10px, $md: 20px, $lg: 50px);
    --component-size: var(--ig-size-medium);
  }
  ```
  
  In this example, the `--is-medium{:sass}` variable becomes `1`, while the other two (`--is-small{:sass}` and `--is-large{:sass}`) remain `0`. This happens because the `--component-size{:sass}` variable is set to `--ig-size-medium{:sass}`. As a result, the parameters passed to the `sizable(){:js}` function: `$sm: 10px, $md: 20px, $lg: 50px{:sass}` — resolve to `0, 20px, 0{:sass}` after the calculations. 
  The function then uses the Sass `max(){:js}` function on the three values to extract the positive one — in this case, `20px{:sass}` — and applies it to the element.
