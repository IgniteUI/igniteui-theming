Typography is the system that controls how text looks in your application — things like font, size, weight, and spacing. It makes sure that headings, body text, captions, and other text elements are consistent and readable across your application. A well-structured typography system helps maintain visual consistency and improves the overall user experience.

In Ignite UI Theming, you define the font scales and styling properties you need, and the framework generates the corresponding CSS variables automatically, saving you from writing repetitive font declarations.

With this approach, you can:

- Build a complete type system from a single configuration.

- Keep text styles consistent with your design system.

- Apply type styles easily through mixins, functions, or ready-to-use CSS variables.

The typography in Ignite UI Theming is generated by two main templates: the [$ITypeScale list](https://github.com/IgniteUI/igniteui-theming/blob/f82a03149a0882f9ac5e851d4c9cda06c6e09bc1/sass/typography/_types.scss#L9) and the [$ITypeStyle map](https://github.com/IgniteUI/igniteui-theming/blob/f82a03149a0882f9ac5e851d4c9cda06c6e09bc1/sass/typography/_types.scss#L14), these two templates define all font categories and font properties that will be generated for your typography.

- The `$ITypeScale` list stores all type scales for which variables will be created. These scales are mandatory when generating typography variables. That means you must supply them whenever you use the typography functions and mixins.

- The `$ITypeStyle` map stores all styling properties that will be created as variables for each type scale.

By default the `$ITypeScale` list contains 13 type scales based on the Material Design system:

```scss
$ITypeScale: (
  h1,
  h2,
  h3,
  h4,
  h5,
  h6,
  subtitle-1,
  subtitle-2,
  body-1,
  body-2,
  button,
  caption,
  overline
);
```

You are not required to use all of them, you can customize the list as needed.

By default, `$ITypeStyle` map contains the following properties:

```scss
font-family: inherit,
font-size: null,
font-weight: normal,
font-style: normal,
line-height: normal,
letter-spacing: normal,
text-transform: none,
margin-top: 0,
margin-bottom: 0
```

Each type style has a default value, which will be applied even if you don’t explicitly set it when including the typography.

Let's say that you have the following typography in your design system:
  <table className={`${styles.table} ${styles.table__typography}`}>
    <thead className={styles.table__header}>
      <tr>
        <th>Style</th>
        <th>Size</th>
        <th>Weight</th>
      </tr>
    </thead>
    <tbody className={styles.table__content}>
      <tr>
        <td>H1</td>
        <td>24px</td>
        <td>Medium (500)</td>
      </tr>
      <tr>
        <td>Subtitle</td>
        <td>20px</td>
        <td>Regular (400)</td>
      </tr>
      <tr>
        <td>Body</td>
        <td>14px</td>
        <td>Light (300)</td>
      </tr>
    </tbody>
  </table>
<br/>

The easiest way to convert the typography design system into a usable one is the following:

- First, you need to customize the `$ITypeScale` list and add only the type scales that you need. In this case, we will just have three type scales: `h1{:scss}`, `subtitle{:bash}`, and `body{:sass}`. And also customize the `$ITypeStyle` map and add only the styling properties that you need for your typography. In this case, we will just have `font-family{:css}`, `font-size{:css}`, and `font-weight{:css}`.

```scss
@use 'igniteui-theming/sass/typography/types' as * with (
  $ITypeScale: (
    h1,
    subtitle,
    body
  ),
  $ITypeStyle: (
    font-size: null,
    font-weight: normal,
    line-height: normal
  )
);
```

- After that, you need to create a type scale map using the `type-scale(){:bash}` function, which will contain all of the type scales as keys and their corresponding styling properties as values. You can use the `type-style(){:bash}` function to create the map values, which accepts the styling properties as parameters.

- After we have the type scale map, we can include the typography in our project by using the `typography{:sass}` mixin and passing the font family and the type scale map as parameters.

```scss

$custom-typography: type-scale(
  $h1: type-style(
    $font-size: rem(24px),
    $font-weight: 500
  ),
  $subtitle: type-style(
    $font-size: rem(20px),
    $font-weight: 400
  ),
  $body: type-style(
    $font-size: rem(14px),
    $font-weight: 300
  )
);

@include typography( /* [!code highlight] */
  $font-family: 'Inter, sans-serif', /* [!code highlight] */
  $type-scale: $custom-typography /* [!code highlight] */
); /* [!code highlight] */
```

- This will generate all the necessary CSS variables for your typography, and you can start applying them to your elements. There are a few ways you can apply them, here we will use the `type-style{:sass}` mixin.

```scss
.wrapper {
  @include type-style('body');
}
```

- Now, the `.wrapper{:css}` element will have the `body{:sass}` typography style applied to it, and it will inherit the font family defined in the `typography{:sass}` mixin.
