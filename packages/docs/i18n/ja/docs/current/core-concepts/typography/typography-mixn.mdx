# Typographyミックスイン

  `typography{:sass}` ミックスインは、タイプスケールマップをCSS変数のセットに変換する役割を担います。

	```scss
	@include typography (
      $font-family: 'Inter, sans-serif',
      $type-scale: $custom-typography
  )
	```

  こ2つの必須パラメータを受け入れます。

  - `$font-family` – 使用するフォントファミリ
  - `$type-scale` – カスタムタイプスケールを含む変数

  :::note
  ここで渡されたフォントファミリは、各スケールの `$ITypeStyle` で定義されたフォントファミリよりも低い特定性を持ちます。
  :::
  
  `typography{:sass}` ミックスインを含めた後、まずセレクタ内に含まれているかどうかを確認します。このチェックは、カスタム[is-root()](https://www.infragistics.com/products/ignite-ui-angular/docs/sass/latest/utilities/#function-is-root)関数によって処理されます。ミックスインがセレクタ内にない場合、CSS変数は `:root{:css}` レベルで宣言されます。

  次に、ミックスインに渡されたフォントファミリは、現在のスコープの変数として宣言されます — `--ig-font-family{:sass}` 。
  それと同時に、別の変数 `--ig-base-font-size{:sass}` も宣言されます。このベースフォントサイズは[スタンドアロンファイル](https://github.com/IgniteUI/igniteui-theming/blob/f82a03149a0882f9ac5e851d4c9cda06c6e09bc1/sass/config/_index.scss#L1)から取得され、主に[rem()、em()、px()](../../utility-concepts/converting_functions/converting-functions.mdx)関数の計算に使用されます。

  その後、タイプスケールマップ内のすべてのタイポグラフィタイプに対して、`type-style-vars{:sass}` というカスタムミックスインが含まれます。これは各タイプを調べ、そのスタイルプロパティのそれぞれをスタンドアロンのCSS変数として宣言します。

  結果は次のようなCSS変数のリストになります。

  <CodeBlockHeader title="CSS出力"/>
	```css
  :root {
      --ig-font-family: Inter, sans-serif;
      --ig-base-font-size: 16px;
      --ig-h1-font-size: 1.5rem;
      --ig-h1-font-weight: 500;
      --ig-h1-line-height: normal;
      --ig-subtitle-font-size: 1.25rem;
      --ig-subtitle-font-weight: 400;
      --ig-subtitle-line-height: normal;
      --ig-body-font-size: 0.875rem;
      --ig-body-font-weight: 300;
      --ig-body-line-height: normal;
      --ig-navigation-font-size: 1rem;
      --ig-navigation-font-weight: 400;
      --ig-navigation-line-height: 1.5;
  }
	```
