  各パレットは、ブランドカラー、ニュートラルカラー、機能カラー（原色、グレー、成功カラー、警告カラーなど）をグループ化し、一貫性があり再利用可能なコレクションとしてまとめています。

  カラーパレットを使用することで、製品全体のコンポーネントが一貫したビジュアル言語を共有することが保証されます。値をハードコーディングする代わりに、パレット変数を参照することで、以下が簡単になります：

  - すべてのUI要素間で一貫性を維持

  - テーマやブランド更新を迅速に適用

  - コントラスト対応のカラーペアでアクセシビリティを念頭に置く

  実際には、パレットはカラー使用の唯一の信頼できる情報源として機能します。パレット内の値を更新すると、フレームワーク全体に自動的に伝播し、デザインとコードが完璧に整合します。

  たとえば、デザインシステムが以下のカラーパレットを提供しているとしましょう：

  以下のようにして、使用可能なSCSSパレットに変換できます：

  - まず、.scssファイルにigniteui-themingパッケージを追加します：

  ```scss
  @use 'igniteui-theming' as *; 
  ```

  - 次に、提供されたデザインシステムの色をパレット関数に渡します。
  パレットには2種類あります：すべてのカラー値を直接追加する[手動作成パレット](manually-created-palettes)と、いくつかのキーカラーに基づいてカラー生成関数を使用して完全なパレットを作成する[自動生成パレット](auto-generated-palettes)です。
  
  - この例では、自動生成パレットを作成します。提供されたデザインシステムのカラー値をマップとして[palette()](auto-generated-palettes)関数に渡します。

  ```scss 
  $my-palette: palette(
    $primary: #f34e4e,
    $secondary: #fff6ea,
    $surface: #ebebeb
  );
  ```

  - [palette()](auto-generated-palettes)関数を使用すると、提供されたカラーとは別に、グループごとに追加で11のバリアント、さらに各バリアントのコントラストカラーも生成されます。

  - パレットを作成したら、[palette mixin](palette-mixin) を使用してプロジェクトに組み込む準備が整います。これにより、[palette()](auto-generated-palettes) 関数を使用して取得した Sass マップに基づいて CSS 変数が生成されます。

  ```scss
  @include palette($my-palette);
  ```

  - これにより、パレット内の各色に対応するCSS変数が生成され、それをスタイルシートで使用できます。指定された色の値は、その色グループの`500{:js}`バリアントとなり、その他の明るい色と暗い色は`50{:js}`から`900{:js}`までの範囲になります。
  
  - 生成されたパレットからカラーを参照するには、カラーバリアントには[color()](accessing-the-css-variables)関数を、コントラストカラーには[contrast-color()](accessing-the-css-variables)関数を使用できます。たとえば：

  ```scss
  .demo-box {
    background: color($color: 'primary', $variant: 600);
    border-color: color($color: 'secondary', $variant: 900);
    color: contrast-color($color: 'primary', $variant: 600);
  }
  ```

  生成されたCSS変数を使用することで、デザインシステムの色を整理し、保守性を維持しながら、アプリケーション全体にデザインシステムの色を簡単に適用できます。
