# 手動作成パレット

手動作成パレットは、自分で定義するSassマップです。設定したすべてのカラー値は、`palette{:sass}`ミックスインでパレットをインクルードするとCSS変数として生成されます。追加のバリアントやコントラストカラーは生成されず、マップで定義した値のみが出力に含まれます。

これらは、生成されるCSS変数を完全に制御し、追加の生成値なしでパレットに特定のカラーのみを含めたい場合に便利です。

パレットを手動で作成するには、まずすべてのパレット値を保持する変数を定義する必要があります。Ignite UI Themingのコンテキストでは、パレットはSassマップとして宣言され、マップキーはカラーグループ（例：`primary{:jsonc}`、`secondary{:jsonc}`、`surface{:jsonc}	`）を表します。
     
各カラーグループ自体が、そのバリエーションを定義するマップです。バリエーションはキーと値のペアで表され、キーはバリエーション名（`500{:js}`や`600{:js}`など）、値は実際の色値です。

次の事項に制限はありません：

- 定義するカラーグループの数

- 各グループに含まれるバリアントの数

- カラー値の形式（hex、rgba、hsl()など）

例：

```scss
$custom-palette: (
  'primary': (
    '500': #6797de,
    '500-contrast': white,
    '600': rgba(54, 129, 221, 1),
    '600-contrast': white
  )
);
```

さらに、もちろん一部のカラーグループを手動でマッピングし、`shades(){:js}` 関数を使用して残りのグループのバリエーションを生成することもできます。

例：

```scss
$custom-palette: (
  'primary': (
    '500': #6797de,
    '500-contrast': white,
    '600': rgba(54, 129, 221, 1),
    '600-contrast': white
  ),
  // 二次色グループの色調とコントラストのバリエーションを自動的に生成する
  'secondary': shades(
    'secondary',
    #fff6ea, 
    $IColorShades
  )
);
```

バリアント名（`500{:js}`、`600{:js}`など）は、カラー関数とミックスインでサポートされている終了モードであることに注意してください。各バリアントにノードレベルを追加すると、マップ形式が正しく認識されなくなります。

パレットマップを作成する際、カラーグループとバリアントの両方に任意の名前を付けることができます。唯一の要件は、キーが引用符で囲まれた文字列であることです。

パレットはコントラストカラーもサポートしています。テキストや前景要素の視認性を確保するために、任意のバリアントにコントラストカラーを手動で追加できます。唯一の要件は、バリアント名が`-contrast{:sass}`というサフィックスで終わる必要があることです。これにより、Ignite UIテーマのコントラスト関数がそれを認識できます。

:::danger[Important]
マップキーは必ず引用符で囲んでください。例：`'primary'`、`'secondary'`、`'gray'`、`'500'`、`'500-contrast'`。引用符なしのキーは、すべての場合で正しく動作するとは限りません。
:::

パレットを手動で作成する場合、カラー値にCSS関数を使用できます。たとえば、[light-dark()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/light-dark)関数を使用して、同じ変数内で`light`モードと`dark`モードに異なるカラー値を設定すると、パレットがアクティブなアプリのテーマに自動的に適応します。これにより、ライトモードとダークモード用に別々のパレットを作成することなく、同じバリアントに異なる値を指定できるため、パレットの柔軟性が向上します。

以下の例では、[light-dark()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/light-dark) 関数を使用して、`primary`、`secondary`、`gray` の 3 つのカラー グループすべてに対して、`light` モードと `dark` モードで異なる色値を設定しています。2 つのボックスにはそれぞれ異なる `color-scheme{:sass}` 値が設定されているため、同じカラー バリアントから異なる色値を適用できます。片方のボックスには [light-dark()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/light-dark) 関数の light 値が適用され、もう片方には dark 値が適用されます。

コントラストカラーをハードコーディングする代わりに、`adaptive-contrast(){:bash}` テーマ関数を使用してテキストカラーを設定することで、使用されている値に基づいて適切なコントラストカラーが自動的に選択されます。
