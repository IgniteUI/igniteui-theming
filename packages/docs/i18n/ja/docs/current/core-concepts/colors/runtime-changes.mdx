# ランタイム変更

  すでに見たように、すべての自動生成カラーバリアントは、各カラーグループに渡された`500{:sass}`バリアントカラーに基づいています。
  これらの自動生成カラーの非常に便利な機能は、動的に計算されるため、ランタイムでも更新できるということです。

  これは、`500{:sass}`バリアントカラーを更新するだけで、特定のタイプのすべてのカラーバリアントを再計算できることを意味します。
