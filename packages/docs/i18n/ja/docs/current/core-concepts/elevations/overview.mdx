  エレベーションは、デザインシステムで要素に深さとレイヤーの感覚を与える影です。どのコンポーネントが上にあるか、どれが一緒にグループ化されているか、インターフェースのどの部分が最も注目を集めるべきかを示すのに役立ちます。

  Ignite UI Themingでは、エレベーションはプロジェクト全体で一貫して適用できる再利用可能な影スタイルとして定義されます。box-shadow値を手動で書く代わりに、名前付きのエレベーションレベルを持つエレベーションマップを設定します。そこから、次のことができます：

  - 事前定義されたミックスインと関数を使用して要素にエレベーションレベルを適用する。

  - デザインシステムと一貫したエレベーションスタイルを維持する。

  - すべての影を一度に素早く調整する。

  このように、影の管理がより簡単に、よりスケーラブルになり、常にデザインシステムと一致します。

  エレベーションデザインシステムを使用可能なものに変換する最も簡単な方法は次のとおりです：

  - まず、エレベーションレベルをキーとし、対応するbox-shadow値を値とするマップを作成する必要があります。

  ```scss
  $custom-elevations: (
    'xs': box-shadow(10px 2px 4px 2px rgb(0 0 0 / 40%)),
    'small': box-shadow(10px 6px 6px 2px rgb(0 0 0 / 45%)),
    'medium': box-shadow(10px 8px 6px 4px rgb(0 0 0 / 50%)),
    'large': box-shadow(10px 12px 6px 6px rgb(0 0 0 / 55%)),
    'xl': box-shadow(10px 16px 6px 8px rgb(0 0 0 / 60%)),
    '2xl': box-shadow(10px 20px 6px 10px rgb(0 0 0 / 65%)),
  );
  ```

  - その後、[elevations](custom-elevations#including-the-elevations-map)ミックスインを使用してマップをインクルードできます。これにより、作成したマップに基づいてエレベーションCSS変数が生成されます。


  ```scss
  .btn-wrapper {
    @include elevations($custom-elevations);
  }
  ```

  - これで、スタイルシートで生成されたCSS変数を使用する準備が整いました。[elevation()](custom-elevations#using-the-elevations-css-variables)関数に目的のエレベーションレベルをパラメータとして渡すことで、要素に適用できます。

  ```scss
  .button1 {
    box-shadow: elevation('small');
  }
  ```
	
	これにより、マップから対応するbox-shadow値が要素に適用されます。特定のエレベーションレベルの影スタイルを変更したい場合は、マップ内の値を更新するだけで、そのエレベーションレベルが使用されているすべての場所に反映されます。
