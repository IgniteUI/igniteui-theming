# 概要

Ignite UIテーマフレームワークは、プラットフォームを横断してデザインシステムを実装・利用するための包括的なソリューションを提供します。デザイナーや開発者は、このフレームワークを活用することで、色、タイポグラフィ、間隔、高さなど、デザインシステムの概念を定義、カスタマイズ、維持することができます。豊富なSassミックスイン、関数、データ構造を基盤とするこのフレームワークは、レイアウトやコンポーネントのデザイン実装時に使用できるデザイントークンの作成を可能にします。

## フレームワークが解決する課題 {/* #what-problems-the-framework-solves */}

プレーンな CSS でデザインシステムを構築・維持するには、多くの手作業が必要になることが多いです：

- **必要な色の値は多数です**。シンプルなパレットでも、各ブランドカラーの複数の色合いと、テキストやUIの状態に対応するアクセシブルな前景色が必要です
- **アクセシビリティの維持が難しい** — すべてのカラ―組み合わせのコントラストをチェックする必要があり、見落としがあると UI の一部が利用できなくなることがあります。
- **グローバルな変更は時間がかかる** — シャドウ、間隔、丸み、その他のデザインプロパティを更新するには、多くの個別のスタイル宣言を探し回る必要があります。
- **コンポーネントのサイズ調整には追加の作業が必要です** — 小、中、大のコンポーネントまたはレイアウトサイズをサポートするには、通常、スタイルの複製または追加のレスポンシブロジックが必要です。

Ignite UI Theming は、デザイントークンの生成と管理を自動化することで、その手作業を軽減します。わずか数個のベースカラーの入力だけで、カラ―シェード、アクセシブルなコントラストカラー、適用に必要な CSS 変数を含む完全なテーマ基盤を生成できます。

また、システム全体の調整を行うための集中制御変数も提供します。コンポーネントごとにスタイルを更新する代わりに、間隔、丸み、高さ、サイズなどの値を一箇所で変更するだけで、その変更がアプリケーション全体に反映されます。

フレームワークは基礎となる計算を処理し、アクセシビリティ要件の遵守を支援し、どのスタイリング手法でも使える標準的な CSS 変数を出力します。これにより、開発者はトークンの手動管理に費やす時間を減らし、デザインの意思決定により多くの時間を割けます。

## なぜ Sass をフレームワークに選んだのか {/* #why-we-chose-sass-for-our-framework */}

Ignite UI Themingの開発において、私たちの目標は、一貫性があり柔軟なデザインシステムを簡単に作成できるようにすることでした。ネイティブCSS変数は強力ですが、それだけでは複雑なテーマ構造を管理するために必要なツールがまだ揃っていません。Sassはそのギャップを埋めてくれます。制御フローや論理演算子（`if`、`for`）、データ構造（`map`、`list`）、そして`functions`や`mixins`といった機能のおかげで、プログラミング言語に近いものとなっています。これらの機能により、ロジックの追加、コードの再利用、スタイルの動的な生成が可能になります。これらは、プレーンなCSSではまだ実現できないことです。Sassはこれらの利点を活用することで、整理され、再利用可能で、保守しやすいテーマフレームワークを構築するために必要な、CSSに欠けていた機能を提供してくれました。

## Sassのメリット {/* #sass-benefits */}

**マップとリストによる構造化データ：**  
Sassはマップとリストを提供しており、これらはデザインシステムのモデリングに最適です。パレット、タイポグラフィのスケール、間隔、高さなどをすべてマップに保存できます。これにより、これらの構造の保守、参照、更新が容易になります。値を一度変更すれば、すべての箇所に反映されます。

**関数とミックスインによる再利用可能なロジック：**  
CSSにはまだ関数やミックスインがないため、再利用可能なスタイルやロジックを作成することができません。Sassの関数とミックスインは、ロジックをカプセル化してスタイル間で再利用できるようにすることで、この問題を解決します。関数は値を生成してロジックを処理し、ミックスインは一貫して適用できる再利用可能なスタイルのブロックを定義します。

**モジュールによるスケーラビリティ：**  
Sassモジュールを使うことで、Ignite UIのテーマ設定を論理的な部分（色、タイポグラフィ、ユーティリティ、間隔など）に分割し、必要な時に必要なものだけをインポートできます。これにより、コードベースが整理され、保守しやすく、拡張性も高まります。

**より良い開発者体験**  
数行の Sass で、パレット、タイポグラフィ、エレベーションを含む完全なデザインシステムを生成し、CSS 変数にコンパイルできます。開発者はすべての変数を手動で宣言する必要がなく、フレームワークが重い処理を行いながらもクリーンで標準に準拠した CSS を出力します。これにより、開発者は定型作業ではなくデザインの意思決定に集中できます。

Ignite UI ThemingはSassで構築されているため、Sassをサポートする環境であればどこでも動作します。プロジェクトまたはシステムにSassがインストールされていれば、Ignite UI Themingを使用できます。
